## Investment Property — rental schedule

Goal: build the net rental result (income − deductions) for the ATO rental schedule, and keep the
repairs-vs-capital line clean because that's where audits bite.

### Rental INCOME (`investment-property/rental-statements/`)
- [ ] Rent received in FY (from agent's annual statement — full 1 Jul → 30 Jun)
- [ ] Other income: reimbursements, insurance payouts for lost rent, retained bond

### Deductible EXPENSES

**Loan (`loan-interest/`)**
- [ ] Interest charged on the loan for FY (bank annual interest summary) — the biggest line
- [ ] Note: only the portion of the loan used to acquire/improve the property is deductible; redraw for private use is not
- [ ] Borrowing expenses (LMI, loan setup) — deducted over 5 years, not upfront

**Ongoing (`expenses/`)**
- [ ] Council rates
- [ ] Water rates/charges
- [ ] Strata / body corporate fees
- [ ] Property management fees + letting/agent commission
- [ ] Landlord & building insurance
- [ ] Land tax (if assessed)
- [ ] Advertising for tenants
- [ ] Cleaning, gardening, pest control
- [ ] Council/utility charges you paid (not tenant)

**Repairs vs Capital (`capital-works-vs-repairs/`)** ← get this split right
- [ ] **Repairs & maintenance** (restoring existing) → deductible immediately
- [ ] **Capital improvements** (new/better than original) → capital works @ 2.5%/yr over 40 yrs (Div 43)
- [ ] Initial repairs (fixing defects present at purchase) → NOT immediately deductible, capitalised
- Rule of thumb: like-for-like fix = repair; upgrade/new asset = capital

**Depreciation (`depreciation-schedule/`)**
- [ ] Quantity surveyor depreciation schedule (if you have one — worth getting if property is newish)
- [ ] Div 40 plant & equipment (carpet, appliances, blinds, hot water) — note post-May 2017 second-hand rules
- [ ] Div 43 capital works (structure) @ 2.5%/yr

### Purchase / sale & CGT (`purchase-sale-records/`)
- [ ] Only relevant if bought/sold this FY — keep contract, settlement statement, stamp duty, legals
- [ ] If NOT sold: still stockpile these records for the eventual CGT calc (cost base)

## Open questions
- Self-lodge via myTax vs. registered agent (agent extends due date past 31 Oct; fee deductible next year)
- Do you have a **quantity surveyor depreciation schedule**? If not and the property is post-1987 build or renovated, one usually pays for itself.
- Is the property **positively or negatively geared** this year? Drives the net result on your assessment.
- Any period the property was **not genuinely available for rent** (private use / vacant-not-marketed)? Apportions deductions.
