# Treatment Options

## Principle

Treatment is layered: foundational measures that start now, targeted interventions contingent on diagnostic subtype, and refractory options reserved for when conservative + targeted approaches plateau. Address the triad as a single problem — most treatments work across multiple domains.

If the dominant picture is **megarectum / rectal hyposensitivity** (likely), the framing changes from "disimpact then maintain" to **"scheduled emptying to break the distension/desensitisation cycle, then sensation retraining"**. This is a 6–12 month process, not weeks.

---

## Phase 1 — Start now (no further workup needed)

### Initial bowel reset
- **Confirm whether disimpaction is actually needed** via DRE or plain X-ray on a between-BM day. If rectum is heavily loaded mid-cycle:
  - High-dose oral PEG 3350: ~8 Movicol sachets/day for 2–3 days then reassess
  - Alternative: enemas (sodium phosphate, microlax), occasionally manual disimpaction under specialist care
- If no classical impaction (just hyposensitivity / megarectum): skip the high-dose phase and go straight to scheduled emptying

### Maintenance bowel regimen
- **Daily PEG 3350** (Movicol/Osmolax), titrated to soft formed stool — long-term, not rescue. Most patients with megarectum need it indefinitely.
- **Scheduled daily toilet sit** post-breakfast (gastrocolic reflex), regardless of urge — the point is breaking the distension cycle and leveraging time-based retraining
- **Footstool / squat position** (~35° hip flexion)
- **Soluble fibre (psyllium)** — only after rectum decompressed; slow titration; insoluble fibre often worsens dyssynergia
- **Glycerin or bisacodyl suppositories** as outlet aid if needed
- **Stimulants (senna)** — rescue only, not maintenance
- Max 5-minute toilet sits, no straining

### Continue/optimise pelvic floor physiotherapy
- Confirm with her current physio: subtype, treatment focus (down-training vs strengthening), progress
- Consider transitioning to a physio with **sexual medicine subspecialty** if plateaued
- Ensure they're addressing all three domains (bowel, bladder, sexual)

### Medication review — CLOSED (Jul 2026)
- Never on OCP, never on SSRIs, **no other regular medications.** Medication-induced contribution excluded entirely; the whole symptom picture is drug-free baseline.
- The sexual-function arm is therefore mechanical/neural (± endocrine) — the floor/nerve treatment pathway addresses it directly.
- Hormone panel still worthwhile: endogenous low free T, thyroid, prolactin remain unscreened (and are now the only non-mechanical candidates left).

### Vulvar neuralgia — Phase 1 layer (added July 2026)
- **The bowel regimen IS nerve treatment**: every strain is another stretch injury to the pudendal nerve. No-straining discipline now has a second, more urgent justification.
- **Physio focus shifts firmly to down-training / release work** — a hypertonic floor with an irritated nerve must not be strengthened. Describe the symptom precisely at the next session: "left-sided electric shocks beside the vaginal opening, spontaneous, relieved by pressure, worst lying down."
- **Symptom log**: time, position, activity, duration of each episode — this is diagnostic data; characterise before suppressing.
- **If it escalates past tolerable**: topical first — compounded lidocaine 5% ointment to the site (matches the pressure-relief responsiveness, no systemic effect).
- **Oral agent caution**: standard first-line neuropathic drug (amitriptyline) is strongly constipating — wrong drug for her specifically. If an oral agent is ever needed, pregabalin/gabapentin fit better. Raise this proactively with the GP.
- **Watch item (time-limited)**: vesicles/ulcers/rash appearing at the site → HSV prodrome, GP visit, different pathway entirely.

## Phase 2 — Targeted treatment by diagnostic finding

| Finding | Treatment |
|---|---|
| **Dyssynergic defecation** (manometry + failed balloon expulsion) | Intensive **biofeedback** — 4–6 sessions over 8–12 weeks. 60–80% response in RCTs. Gold standard. |
| **Rectal hyposensitivity** (elevated sensation thresholds on manometry) | Sensory retraining via rectal balloon distension training — increases sensitivity over weeks/months |
| **Slow-transit constipation** (Sitz markers / capsule) | **Prucalopride** (Resotran, PBS-listed for women refractory to laxatives) — 5-HT4 agonist. **Linaclotide** (Constella) — guanylate cyclase-C agonist. Both strong RCT evidence. |
| **Rectocele** (defecography) | Pelvic physio first; vaginal pessary; surgical repair (transvaginal or STARR) if symptomatic and refractory |
| **Internal rectal intussusception** | Conservative first; **ventral mesh rectopexy** if refractory |
| **Full-thickness rectal prolapse** | **Surgical** — laparoscopic ventral rectopexy is current standard |
| **Chronic anal fissure** | **Topical GTN 0.2% or diltiazem 2%** first line (~50–60% heal); **botulinum toxin** if fails; **lateral sphincterotomy** for refractory (>90% heal, small continence risk). Treating fissure often unlocks the whole bowel cycle. |
| **Detrusor overactivity** (urodynamics) | Bladder retraining + **mirabegron** (beta-3, cleaner side effects) or solifenacin/oxybutynin; **botulinum toxin to detrusor** if refractory |
| **Stress urinary incontinence** | Pelvic floor physio; vaginal pessary; **mid-urethral sling** surgery if refractory |
| **Detrusor-sphincter dyssynergia** | Biofeedback for pelvic floor relaxation during voiding (same physio sessions as bowel) |
| **Bladder hyposensitivity** | Scheduled voiding (timed, not urge-driven) — parallel to scheduled bowel emptying |
| **Endometriosis** | Hormonal suppression; **laparoscopic excision** (excision > ablation) |
| **Pudendal neuralgia confirmed** (physio reproduces symptom ± clinical picture) | Nerve-focused physio (glides, internal release) first; **image-guided pudendal nerve block** — simultaneously therapeutic and confirmatory (block abolishing the shocks proves the diagnosis); pulsed radiofrequency if blocks help but don't last |
| **Tarlov cyst / tethered cord / sacral pathology** (MRI L/S spine) | Neurosurgical / pain specialist review — **sequence this result first: a positive finding changes everything upstream.** Not always treated, but the diagnosis itself is informative |
| **Low free testosterone (with raised SHBG from OCP)** | Discontinue OCP trial; **off-label physiologic testosterone therapy** via sexual medicine physician |
| **Hypothyroidism / hyperprolactinaemia** | Treat directly — both reverse sexual dysfunction component |
| **Hypermobility / hEDS** | Multidisciplinary management; modify pelvic floor approach (avoid overstretching) |

## If the MRI confirms tethered cord / sacral lesion — surgical untethering (added 17 Aug 2026)

**What:** neurosurgical release — small lumbosacral laminectomy, division of a tight/fatty filum or release of a lipoma; adult case ~2–3 h, a few days in hospital. Outcomes: pain improves in the large majority; progression halted (primary goal); bowel/bladder/sexual function improves in a meaningful minority, stabilises in most, decades-old deficits often don't fully recover → the pelvic floor ladder above still runs, downstream of the fix.

**Coverage (verified 17 Aug 2026 on MBS Online):** **MBS item 40112** — "Tethered cord, release of, including lipomeningocele or diastematomyelia, multiple levels, including laminectomy and rhizolysis" — schedule fee **$2,860.10**, 75% in-hospital benefit **$2,145.10**. Standard funded neurosurgical procedure. (Related: 51071 removal of intradural lesion, $2,992.25 — relevant if the finding is a lipoma/cyst rather than a filum.)

| Pathway | Cost to her | Notes |
|---|---|---|
| **Public hospital, public patient** | **$0** (Medicare card required) | Adult tethered cord done at NSW teaching hospitals w/ neurosurgery (RPA, RNSH, POW, Westmead, St George, Liverpool). Cost is time: clinic wait weeks–months, then elective list; progressive neuro symptoms usually Cat 1–2 (30–90 d) but surgeon's call. |

| **Private, self-funded** | ~$25–45k all-in (est.) | Not sensible if public is available. |

**Recommended move — consult privately, operate publicly:** GP gives two referrals — public neurosurgery clinic at a teaching hospital + a *named* referral to a spine neurosurgeon who also holds a public appointment there. One private consult (~$350–500, ~$80–150 Medicare back) → seen in 1–3 weeks, films read by the right person, then listed for surgery *as a public patient* at their hospital. Bring MRI images.

## Phase 3 — Refractory / advanced options

After 6–12 months of properly-executed conservative + targeted treatment without meaningful change.

### Sacral neuromodulation (SNS)
**Most relevant advanced option for the triad — weight increased July 2026:** the same S3 target also treats pelvic neuropathic pain, so one intervention now covers bowel + bladder + the new neuralgia. Implanted device stimulates S3 nerve roots; evidence-based for urinary urge incontinence, faecal incontinence, and chronic constipation. Emerging evidence for sexual function improvement secondary to pelvic neuromodulation. Two-stage: trial lead → permanent implant if responsive. Reversible. ~50–60% sustained response. Available at St Vincent's, RPA, Royal North Shore.

### Transanal irrigation
Wash-out system (Peristeen, Navina). Less invasive than surgery; widely used in refractory constipation and neurogenic bowel. Worth knowing as a step before surgical options.

### Subtotal colectomy with ileorectal anastomosis
Last-resort surgical option. Only for **confirmed isolated slow-transit constipation with normal anorectal function** — so dyssynergia must be excluded first. Significant morbidity (loose stools, possible incontinence).

### Antegrade continence enema (Malone / ACE)
Surgical stoma (usually via appendix) for antegrade colonic flushing. Used for refractory constipation/incontinence. Less drastic than colectomy, reversible.

### Pudendal nerve interventions
If pudendal neuropathy confirmed: nerve glides, pulsed radiofrequency, image-guided nerve blocks; rarely surgical decompression.

## Sexual function — its own treatment ladder

Most overlaps with PFD treatment (the foundation). Dedicated approaches:

- **PFD-targeted** (foundation): down-training, internal release work, dilator therapy if vaginismus, vaginal valium suppositories under sexual medicine guidance for refractory hypertonicity
- **Hormonal**: correct any deficiency; OCP discontinuation trial; off-label testosterone if free T low
- **Mindfulness-based cognitive therapy for sexual dysfunction** — Lori Brotto's protocol has the strongest RCT evidence for female sexual interest/arousal/orgasm disorders. Book: *Better Sex Through Mindfulness*.
- **Sensate focus / structured couples sex therapy** — solid evidence base for orgasmic disorders
- **Clitoral vacuum device** (Eros-CTD) — evidence for FSAD; available without prescription
- **Vibrator therapy** — clinically validated for orgasmic disorder when used systematically under sex therapist guidance
- **Bremelanotide (Vyleesi)** — for HSDD; less directly relevant for anorgasmia
- **EMDR / trauma-focused therapy** — if relevant history; can improve sexual function and reduce pelvic floor guarding

## Realistic expectations

- **Bowel pattern**: with proper sequenced care (disimpaction if needed + scheduled emptying + PEG + biofeedback + sensation retraining + structural correction if needed), substantial improvement is realistic for most. May not return to fully normal urge-driven defecation; indefinite scheduled emptying + PEG is a reasonable steady state.
- **Urinary symptoms**: very likely to improve in parallel as PFD is treated; specific interventions if urodynamics shows a discrete diagnosis.
- **Sexual function**: the hardest and slowest. Usually improves once pelvic floor changes, but may need 6–18 months of layered treatment + dedicated sexual medicine work. Anorgasmia responds to combined PFD treatment + mindfulness-based sex therapy + addressing any hormonal contributor.
- Total timeline to meaningful change across all three domains: **6–18 months**. Not weeks.
- This is workable, not hopeless. Most women with this picture get a fraction of the available treatment because the triad framing is missed.
