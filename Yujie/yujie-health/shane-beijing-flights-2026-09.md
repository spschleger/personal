## ⚠️ Trap fares
The headline "Cheapest" prices (A$1,037–1,131) all pair a fine outbound with a junk return:
- Hainan A$1,131 → return is 44 h with a 31 h layover in Haikou.
- China Eastern A$1,220 → return is 2 stops (SHA + WUH), 32 h.
- Air China A$1,333 → return is a 3-stop self-transfer, 44 h.
Real round trips with sane legs both ways start ~A$1,426.
