# Foundational Training Program (lifting + mobility + core)

**Built:** 2026-06-20 | Pairs with `recomp-protocol-2026.md` and `scoliosis-rehab-research.md`.
**Scope:** Layers 1 (lifting), 2 (mobility), 3 (core/sensorimotor). **Layer 4 — curve-specific scoliosis self-correction — deferred** until diagnostic data (X-ray/Cobb/curve type) + a Schroth/SEAS assessment. A slot is reserved for it below.

## Governing principles (scoliosis + deficit context)
- **Lift symmetrically as the foundation** — machine/cable work is safe and primary. Don't turn lifting into rehab.
- **Spine decompression is a priority** — machine/cable/supported movements minimise axial load; no heavy barbell squat/deadlift/standing press. Keep erectors strong via back extensions/pull-throughs (load the muscle, spare the compression).
- **Add unilateral accessories** every session (single-arm/leg) — addresses asymmetry without pathologising it.
- **Pain-gate:** train only when baseline back pain ≤4/10; allow ≤1-point rise within a session; if daily pain is higher, mobility/PT first.
- **Technique > load**, especially in the deficit (re-injury risk is real weeks 5–8). Autoregulate by RPE, leave 1–2 reps in reserve, no early failure.
- **Brace/breathe:** 360° diaphragmatic breath + braced trunk on loaded lifts. Belt fine for heavy hinges/squats.
- **Symmetric default for now** (no curve data) — train both sides equally; revisit asymmetric corrective bias only once Layer 4 is assessed.
- **No heavy axial hinge** — posterior chain trained via seated/lying leg curl, cable pull-through, and 45° back extension instead of barbell deadlift/RDL.

## LAYER 1 — Lifting (machine/cable hypertrophy, spine-decompressed)

**Two rotatable templates — Push and Pull — repeated across the 4 Sydney days (Push / Pull / Push / Pull).** Machine/cable/supported bias to minimise axial spinal loading; trainable seated or chest-supported wherever possible. Each muscle hit 2×/week.

### PUSH (chest / shoulders / triceps / quads)
- Machine chest press — 3 × 8–12
- Incline machine press or pec deck — 3 × 10–12
- Seated machine shoulder press (back supported) — 3 × 8–12
- Cable or DB lateral raise — 3 × 12–20
- Leg press — 3 × 10–15 *(supported spine; still loads hips/femur for bone)*
- Leg extension — 3 × 12–15 *(single-leg = unilateral option)*
- Cable triceps pushdown + overhead cable extension — 3 × 10–15

### PULL (back / rear delts / biceps / hamstrings / glutes)
- Lat pulldown — 3 × 8–12
- Chest-supported machine row — 3 × 8–12 *(no spinal load)*
- Single-arm cable row — 2–3 × 10–12/side *(unilateral)*
- Reverse pec deck or cable face pull — 3 × 15–20
- Seated/lying leg curl — 3 × 10–15
- 45° back extension or cable pull-through — 3 × 10–15 *(erectors/glutes WITHOUT compression — keeps the back strong & protective)*
- Cable + incline-DB biceps curl — 3 × 10–15

**Why it fits:** hypertrophy doesn't need spinal compression — machines/cables grow muscle just as well while sparing the spine, lowering injury risk in the deficit and simplifying execution. With nothing heavily axial, the back is also de-risked around the drives + shifts.

**Keep the back STRONG, not just decompressed:** the back extension / pull-through + Layer-3 anti-movement core are deliberately retained — a strong erector/core is spinal *protection*. Decompress the load, don't neglect the muscle.

**Progression (deficit):** add a rep or small load when the top of the range is clean; holding muscle in a deficit = the recomp working. No PR-chasing while cutting.

## LAYER 2 — Mobility / flexibility (the lead priority)

Whole-body foundation, weighted toward **spine (decompress + mobilise), hips, and breathing** — what the scoliosis, the periodic back pain, the physical day shifts, and the lifting all demand. **Rules:** consistency > intensity (daily short beats occasional long); stretch into mild tension, never pain; **symmetric for now** (no curve-specific bias until a PSSE assessment); breathing is part of it.

### A) Daily foundational flow (~10 min — every day, incl. work days)
1. 360° diaphragmatic breathing — 8–10 slow breaths *(ribcage expansion; Schroth tie-in, un-cued for now)*
2. Cat–cow — 8–10
3. Open book (T-spine rotation) — 8/side
4. Thread-the-needle — 5/side
5. World's greatest stretch — 5/side *(hip flexor + T-spine + hamstring in one)*
6. 90/90 hip switches — 8/side
7. Kneeling hip-flexor stretch — 30–45 s/side
8. Deep squat hold — 60 s *(hips/ankles + decompression; hold a rack/TRX if needed)*
9. Knee-to-wall ankle rock — 10/side
10. Dead hang — 20–30 s *(spinal decompression — high value for you, if a bar's available)*

### B) Pre-lift prep (~5 min, day-specific — primes what you're about to load)
- **Push days:** shoulder CARs, band pull-aparts/dislocates, wall slides, leg swings, bodyweight squat-to-stand, ankle rocks.
- **Pull days:** cat-cow, open book, hip CARs, hamstring leg swings, glute bridges, band face pulls.

### C) Dedicated flexibility + decompression (1–2×/week, ~20–30 min — for real range gains)
Longer static holds (45–90 s; optional contract-relax/PNF for faster gains):
- Hamstrings (lying, strap)
- Hip flexors (couch stretch / kneeling lunge)
- Adductors (frog / butterfly)
- Glutes & piriformis (figure-4 / pigeon)
- Pecs & lats (doorway pec; lat hang on a rack)
- T-spine extension over a foam roller or bench
- Hip CARs + 90/90 end-range work
- Spinal decompression: hanging, legs-up-the-wall, supported reclined positions
- Finish: 2–3 min slow breathing

### D) Post-shift decompression (Mudgee, ~5–10 min — recovery from 12 hrs on your feet)
- Dead hang — 2–3 × 20–30 s
- Standing forward fold — 30 s
- Couch / hip-flexor stretch — 45 s/side *(counters the standing + bending)*
- Child's pose — 60 s
- Legs-up-the-wall — 3–5 min *(venous return, low-back relief, downregulation)*
- Diaphragmatic breathing — 2–3 min

### E) Soft-tissue release (adjunct — roller, ball, massage gun, ART)
**What it does:** real but **transient, neurophysiological** benefits — short-term ROM, reduced soreness, warm-up readiness, downregulation. NOT structural "fascia release / breaking up adhesions" (myth — that's the nervous system, not tissue remodeling). It *opens the window* for mobility/strength work; it doesn't replace the stretching/loading that builds lasting range.

**Uses:**
- **Pre-lift (30–60 s/area):** quads, glutes, lats, T-spine — boosts ROM/readiness without the performance dip of long static stretching.
- **Post-shift recovery:** roll/gun sore areas + downregulate. A massage gun lives well in the car/camp.

**Tools:** foam roller (general), lacrosse/massage ball (targeted — glutes, piriformis, pecs, feet, upper traps), massage gun (convenient pre/post).

**Back/scoliosis caveats:**
- **Around the spine, not on it.** Roll glutes, hips, lats, and T-spine (roller under upper/mid back for extension is great) — **never grind directly on the lumbar spine, spinous processes, or the curve.** Gun on muscle bellies only, not over spine/bone.
- Gentle, not aggressive digging — especially near the curve.

**Practitioner work (ART / remedial / sports massage):** useful *occasional* adjunct for stubborn areas given the physical job + back — tune-ups, not a cornerstone. A good soft-tissue therapist ≠ the chiropractic "scoliosis correction" marketing in `scoliosis-rehab-research.md` (fine for soft tissue, not a curve fix).

**Going deeper (optional):** the joint-health backbone is **CARs (Controlled Articular Rotations)** — daily hip/shoulder/spine CARs maintain active range. For a methodical flexibility system that's the **FRC (Functional Range Conditioning)** route; the Schroth/SEAS corrective layer (deferred) layers on top once you have curve data.

**OPEN ACTION — app for Layer 2 (don't overthink):** do **GOWOD's free assessment** (free, ~10 min — gives your mobility profile + daily follow-along video). Trial a couple of weeks. If it clicks → that's the Layer 2 engine. If not → **[P]rehab** (PT-built, back-safe) as plan B. Don't stack apps or compare five — one free trial, decide from use. The daily flow matters more than the tool. Other options surveyed (ATG, GMB, Kinstretch, Pliability) in conversation if needed. Avoid any loaded spinal flexion (e.g., ATG Jefferson curl) regardless of app.

## LAYER 3 — Core / sensorimotor (2–3×/week)

Evidence-supported for adult scoliosis low-back pain. Bias toward anti-movement (resisting rotation/side-bend/extension), trained **both sides equally**.

- **Anti-rotation:** Pallof press — 3 × 10/side
- **Anti-lateral-flexion:** suitcase carry — 3 × 20 m/side; side plank — 3 × 30–45 s/side
- **Anti-extension:** dead bug — 3 × 8/side; hollow hold or plank — 3 × 30–45 s
- **Loaded carries:** farmer's + suitcase walks (also grip/traps/posture)

**Placement:** finisher on Pull A + Push B; one standalone mini-session on the Thu mobility day or a run day.

## Weekly map (roster-aware: 4 Sydney training days, Fri–Sun day shifts)

Commute: drive Sydney→Mudgee **Thu night**, back **Sun night**. All lifting + runs live in the **Sydney block (Mon–Thu)**; Fri–Sun are 12-hr day shifts = activity/NEAT (feeds the deficit) + recovery — no formal training needed there.

**Back-protective by design:** with machine/cable spine-decompressed lifting (Layer 1) there's no heavy axial load to sequence around — the back goes into the drives + shifts fresh regardless. Just alternate Push/Pull.

| Day | Where | Session |
|---|---|---|
| Mon | Sydney | **Push** + Run 8–10 km Z2 + daily mobility |
| Tue | Sydney | **Pull** + core + daily mobility |
| Wed | Sydney | **Push** + Run 8–10 km Z2 + daily mobility |
| Thu | Sydney → drive PM | **Pull** + core + daily mobility; then drive to Mudgee |
| Fri | Mudgee | 12-hr day shift + daily mobility/decompression |
| Sat | Mudgee | 12-hr day shift + daily mobility/decompression |
| Sun | Mudgee → drive PM | 12-hr day shift + daily mobility; drive back to Sydney |

**Notes:**
- **Work days = recovery + activity.** The shifts are physical (high NEAT, supports the cut). Do the daily 10-min mobility/decompression flow — post-shift mobility + breathing genuinely aids recovery.
- **Mudgee Anytime Fitness = flexibility/insurance, NOT extra load.** Use it for: (a) a **make-up session** if a Sydney day gets eaten by appointments/ventures; (b) **mobility/decompression** after a shift; (c) an **optional easy Z2 spin/walk** on a work day *only if feeling good*. Do **not** default to adding heavy lifts onto the 12-hr shift days — recovery in a deficit + back protection. The four lifts belong in the fresh Sydney block.
- **Longer mobility session:** fold into a Sydney morning or a calmer post-shift evening — flexible, 1×/week.
- **Runs:** 2 in the Sydney block (Mon/Wed). If a work weekend leaves you beat, dropping to 1 is fine — the shifts hold the activity floor; the run is for the BP/Z2 benefit.
- **Thursday = lift + drive:** keep it a normal Pull session, no run, fuel/hydrate for the drive into the shift block.
- **Scaling guardrail (don't add a 5th/6th lift day speculatively):** in a deficit + 3× 12-hr shifts, recovery is the constraint. P/P/P/P already = 2×/week per muscle (effective). Only add volume if the recovery signals earn it (RHR stable/down, sleep solid, lifts holding, weight trending right). If the "do more" itch hits, channel it into mobility/decompression + sleep, not extra lifting.
